# Smart Office System

An ASP.NET Core MVC web application built to streamline office management, employee tracking, task delegation, and attendance management.

## 🚀 Key Features
- *Manager Module:* Assign tasks to employees, post office notices, and oversee team activities.
- *Employee Portal:* View assigned tasks, track attendance, and check daily updates.
- *Data Persistence:* Integrated database handler for seamless CRUD operations.

## 🛠️ Tech Stack
- *Framework:* ASP.NET Core MVC (.NET 10.0)
- *Language:* C#
- *Frontend:* Razor Views (.cshtml), HTML, CSS, JavaScript, jQuery
- *Database:* SQLite / Relational DB
